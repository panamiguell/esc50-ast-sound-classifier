# esc50-ast-sound-classifier

Environmental sound classification on ESC-50 (animals, natural soundscapes, human, domestic and urban sounds) by fine-tuning the Audio Spectrogram Transformer (AST, pretrained on AudioSet) with Hugging Face. Log-mel spectrogram pipeline, 2-epoch fine-tuning and evaluation with precision, recall, F1 and confusion-matrix analysis per class and category.

> Mini-project 4 of the course *Técnicas de Deep Learning* (MAIA-4213), MSc in Artificial Intelligence, Universidad de los Andes.

## Problem

ESC-50 contains 2,000 five-second recordings in **50 classes** (40 clips each), grouped into **5 major categories**:

| Category | Classes |
|---|---|
| Animals | dog, rooster, pig, cow, frog, cat, hen, insects, sheep, crow |
| Natural soundscapes and water | rain, sea waves, crackling fire, crickets, chirping birds, water drops, wind, pouring water, toilet flush, thunderstorm |
| Human, non-speech | crying baby, sneezing, clapping, breathing, coughing, footsteps, laughing, brushing teeth, snoring, drinking / sipping |
| Interior / domestic | door knock, mouse click, keyboard typing, door creaks, can opening, washing machine, vacuum cleaner, clock alarm, clock tick, glass breaking |
| Exterior / urban | helicopter, chainsaw, siren, car horn, engine, train, church bells, airplane, fireworks, hand saw |

The assignment mentions nature categories such as "birds, water, wind and mammals"; the model is trained on the 50 ESC-50 classes and the results are also analysed at the level of the 5 major categories.

**Data:** loaded from the Hugging Face Hub as indicated in the assignment (`load_dataset("confit/esc50-demo", "fold1", ...)`). **Audio is not versioned in this repository**: it is downloaded and cached automatically the first time the notebook runs.

**Model:** [`MIT/ast-finetuned-audioset-10-10-0.4593`](https://huggingface.co/MIT/ast-finetuned-audioset-10-10-0.4593).

## Approach

1. **Audio pipeline:** resampling to 16 kHz mono, 128-bin log-mel filterbanks (25 ms window, 10 ms hop), padding / truncation to 1,024 frames and normalization with the AudioSet statistics used in pretraining.
2. **Validation without leakage:** the official test split (fold 1) is kept for the final report; validation is carved out of the training folds keeping all clips of the same source recording together.
3. **Fine-tuning (2 epochs, as required):** AST with a new 50-class softmax head; comparison of full fine-tuning, head-only training and SpecAugment; three seeds for the final configuration.
4. **Baseline:** MFCC statistics + logistic regression.
5. **Evaluation:** accuracy, macro precision / recall / F1, per-class and per-category metrics, 50×50 and 5×5 confusion matrices, most confused pairs and qualitative analysis of errors with their spectrograms.

## How to run (VS Code)

1. Clone the repository and open the folder in VS Code.
2. Create a virtual environment and install the dependencies:

   ```bash
   python -m venv .venv
   # Windows: .venv\Scripts\activate    macOS / Linux: source .venv/bin/activate
   # Install PyTorch first, with CUDA if you have an NVIDIA GPU: https://pytorch.org/get-started/locally/
   pip install -r requirements.txt
   ```

3. Open `notebooks/01_solucion_ast_esc50.ipynb`, select the `.venv` kernel and run all cells. Internet access is needed the first time (dataset and model from the Hugging Face Hub).

Audio is read with `soundfile` and resampled with `scipy`, so FFmpeg / `torchcodec` are **not** required (they are what `datasets` ≥ 4 would otherwise need to decode audio).

A GPU (CUDA or Apple MPS) is strongly recommended: AST has 86 M parameters and processes 1,212 patches per clip. Each experiment saves its results in `outputs/tables/runs/`; if they already exist the notebook reloads them instead of retraining (`RETRAIN = True` to train again). If the GPU runs out of memory, set `batch_size=4, grad_accum=4` in `CONFIG` (same effective batch) or `grad_checkpointing=True`.

**Smoke test without internet or GPU:** set the environment variable `MP4_QUICK=1` to run the whole pipeline with synthetic audio and a tiny randomly initialized AST (outputs go to `outputs/_smoke_test/`, not versioned). Its metrics are meaningless.
